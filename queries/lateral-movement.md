## 1. Network Logons — Lateral Movement

Logon_Type=3 means authentication happened over the network via SMB or Windows shares rather than at the physical console. This is the primary logon type generated during lateral movement. Look for accounts authenticating to machines they do not normally access, especially from workstation-to-workstation rather than user-to-server.

```spl
index=windows EventCode=4624 Logon_Type=3
| eval user=mvindex(Account_Name,1)
| table _time, host, user, Logon_Type, Source_Network_Address
| sort -_time
```

## 2. Machines Accessed Per Account

Uses `dc(host)` distinct count of hosts to identify accounts that authenticated to more than one machine in a session. A standard user account accessing multiple machines via network logon is a strong lateral movement indicator. The higher the `machines_accessed` count, the more suspicious.

```spl
index=windows EventCode=4624
| stats dc(host) as machines_accessed, values(host) as hosts by Account_Name
| where machines_accessed > 1
| sort -machines_accessed
```

## 3. AD Enumeration Detection — BloodHound

BloodHound and SharpHound enumerate Active Directory by querying LDAP across all domain objects, generating a large volume of Logon_Type=3 events on the Domain Controller in a short window. This query looks for accounts generating more than 10 network logons to DC01 within the last 10 minutes a pattern that is almost exclusively caused by AD enumeration tools in normal environments.

```spl
index=windows host=DC-01 EventCode=4624 Logon_Type=3
| where _time >= relative_time(now(),"-10m")
| stats count by Account_Name, Workstation_Name
| sort -count
| where count > 10
```

## 4. Explicit Credential Usage

EventCode 4648 fires when a logon is attempted using explicitly supplied credentials passing credentials directly rather than using the currently logged-in user's session. This is unusual for human interactive sessions and is typically generated by scripts, scheduled tasks, or lateral movement tools such as Mimikatz, PsExec, or pass-the-hash techniques.

```spl
index=windows EventCode=4648
| eval user=mvindex(Account_Name,0)
| table _time, host, user, Target_Server_Name, Target_User_Name
| sort -_time
```
